# Saneafy

**Saneafy** is a music app for Android phones and Android TV: smooth, continuous listening
without ads, synced lyrics for almost every song, and a clean, familiar look (two styles to
choose from, Classic and Immersive). A free account is enough.

This page is where Saneafy's releases are published.

## Install

You have two options. **Option 2 is recommended**: you get updates automatically.

### Option 1: download the APK

1. On your phone, open the **[latest release](https://github.com/systematiq-one/saneafy-releases/releases/latest)**.
2. Under **Assets**, tap the file ending in **`-ARMv8.apk`**. If it won't install, use the one
   ending in **`-universal.apk`** instead. Android TV: the one ending in **`-TV.apk`**.
3. Open the downloaded file. If your phone asks, allow installing apps from this source.
4. Tap **Install**.

New versions are also offered inside the app.

### Option 2: install with Obtainium (automatic updates)

[Obtainium](https://github.com/ImranR98/Obtainium) installs apps straight from their GitHub page
and keeps them up to date.

1. Install Obtainium from its [releases page](https://github.com/ImranR98/Obtainium/releases/latest).
2. Open Obtainium and tap **Add App**.
3. In **App Source URL**, paste `https://github.com/systematiq-one/saneafy-releases`.
4. Set the APK filter to `^Saneafy-[0-9].*-ARMv8\.apk$`, then tap **Add** and **Install**.

**Requires Android 10 or newer.** Only download the app from this page.

## Good to know

- You sign in on your music service's own login page. Your password goes only to that service;
  Saneafy doesn't store it or send it anywhere else.
- A separate free account for Saneafy is a good idea. Ad blocking can be switched off in
  Settings > Controls.
- Saneafy is an unofficial, independent app, not affiliated with or endorsed by any music
  service. Use it at your own risk. If you can, support the artists you listen to.
